2. Installation

This is the updated guide for the VulcanOS installation process, which may be updated in the future due to possible changes and updates to the OS, please open an issue if this guide doesn't work.

First things first, put the ISO onto a spare flash drive. Plug the flash drive into the PC, boot the PC, and press the appropriate key to enter the BIOS/UEFI. The key varies depending on the manufacturer of your PC or motherboard. Once you're in the BIOS/UEFI, set the USB drive as the primary boot device and reboot the PC.

After that, wait for your machine to boot. When you reach the command line, type: 

bootstrapd

After entering the command, wait for the daemon to load. Once it loads, select your init and then your DE (Desktop Environment).

After completing the setup, reboot your PC. Your machine should then boot into your selected graphical user interface.

3. Bootstrapd

Bootstrapd is a service provided by the operating system during and after installation that allows the user to choose which DE/WM and init system they want to use for their OS.

The DEs currently supported are KDE and XFCE4, while Hyprland and other DEs/WMs will be supported in the future.

As for init systems, the currently available options are SystemD, OpenRC, runit, and SysVinit.

4. Development

Main Development Focus

The current development focus for VulcanOS is expanding compatibility and support across the system. This includes adding support for more desktop environments (DEs) and init systems, while also working toward broader application support and improved system security.

In the far future, VulcanOS aims to develop its own desktop environment and init system, giving the project greater control over the user experience and core system components.

Development Goals

  • Expand support for additional desktop environments and init systems.
  • Improve application compatibility and support.
  • Strengthen security through kernel randomization, memory protection, cryptography, and other randomization techniques.
  • Long-term: develop a native VulcanOS desktop environment and init system.

5. History

VulcanOS began on January 21st, when dudas131, tired of working on Python development, decided to explore operating system development instead.

The Early Names

The project was originally named MonoOS. The name was later changed to OneOS, as MonoOS felt too corporate. OneOS was eventually renamed to VulcanOS because OneOS felt too generic.

How the Project Evolved

During the OneOS era, the project was written mostly in C++. Over time, VulcanOS moved toward being primarily written in C.

Throughout its development, VulcanOS reached several important milestones, including its early kernel development, first successful boots, filesystem and VFS development, working init systems, and desktop environment support. These milestones helped shape VulcanOS from an experiment into the hobbyist operating system it is today.

The project continues to evolve as an experimental x86_64 operating system.
